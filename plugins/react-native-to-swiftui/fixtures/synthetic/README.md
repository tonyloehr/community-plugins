# Synthetic fixture set

These small examples are owned, neutral test material for the plugin's
deterministic checks. They model a counter feature and an intentionally
ambiguous export without depending on any external application, repository,
asset, service, or package installation.

The stable-counter directory contains the happy planning input, explicitly
approved contract, and tiny marked Swift verification target. The
ambiguous-source directory is the fail-closed source-scope input, and
ambiguous-target contains a conflicting target-module contract that must be
rejected before any write authorization.
