# Code of Conduct

This project welcomes respectful, technically rigorous collaboration.

Participants are expected to:

- be constructive and considerate;
- critique ideas and code without attacking people;
- respect privacy and never post credentials, customer data, or private
  communications;
- disclose conflicts of interest when recommending a plugin or dependency;
- help keep the marketplace safe for people with different backgrounds and
  levels of experience.

Harassment, discrimination, threats, doxxing, or deliberately unsafe behavior
are not acceptable. Maintainers may edit, hide, or remove content and restrict
participation when needed to protect the project and its contributors.

Report conduct concerns privately through the repository owner's GitHub
contact route. Do not post sensitive details in a public issue.
